# SAMSAR — план разработки по ответам анкеты

Название игры: **SAMSAR** (рабочее название режима — «Стальной охотник»).
Движок: **Unity 2022.3.62f2**. Платформа: **ПК (Windows)**.

## Что уже работает (этап 1 — вертикальный срез)

Проект собирается в Unity и запускается: меню → 3D-ангар → бой 3×3 км с 30+ машинами → результаты.
Реализовано: проверка снарядов (рикошет/непробитие/пробитие, приведённая броня, углы, дистанция),
критические модули, зона с жёлтой/красной фазой, лут и воздушный груз, уровни I–VII с выбором модулей,
8 машин и 8 умений, боты-мародёры трёх уровней, разрушаемая карта с интерьерами и станцией,
полный HUD, достижения и статистика, ангар, полигон, процедурный звук и эффекты.

## Ближайшие шаги

1. **Онлайн-мультиплеер** (Mirror/FishNet): синхронизация машин, снарядов, зоны и лута; матчмейкинг на 30+.
2. **Реалистичные PBR-текстуры 2К** для каждой машины (сейчас общий набор + оттенок по машине),
   скины камуфляжа.
3. **Импорт моделей окружения**: промышленные цеха, ангары, больше типов домов, детали станции.
4. **Звук** из свободных библиотек: выстрелы, двигатели, попадания, атмосфера.
5. **Оптимизация**: LOD, батчинг, occlusion culling; замер на 30+ машинах.
6. **Достижения и статистика** — расширение, отдельный экран профиля.
7. **Настройка сложности ботов** по группам, тактики в зависимости от класса машины.
