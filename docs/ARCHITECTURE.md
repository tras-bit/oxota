# Архитектура проекта Samsar

## Как всё связано

```
Blender (tools/*.py)                 Unity (game/)
─────────────────────                ─────────────────────────────────────────
tank_lib.py    ──► 4 машины   FBX ─► Assets/Models/Tanks/*.fbx ─► префабы ─┐
props_lib.py   ──► 13 объектов FBX ─► Assets/Models/Props/*.fbx ─► префабы ─┤
make_textures.py ─► PBR 2К    ─────► Assets/Textures/*         ─► материалы ┤
                                                                            ▼
                                              Samsar → 0. СОБРАТЬ ВСЁ (меню редактора)
                                                                            │
                        ┌───────────────────────────────────────────────────┤
                        ▼                                                   ▼
              Assets/Scenes/Main.unity                       Assets/Scenes/Battle.unity
              (ангар, меню, статистика)                      (карта 3×3 км, бой)
```

## Поток игры

1. **Main** — `AngarUI`: выбор машины (4 кнопки), сложность ботов, соло/взвод, статистика и
   достижения. Модель вращается на площадке, справа — таблица ТТХ. Кнопка «В БОЙ» пишет выбор
   в `GameSession` и загружает сцену Battle.
2. **Battle** — `BattleManager.Start()` расставляет участников: игрок, ИИ-напарник (если взвод),
   боты. Он же ведёт таймер, детекцию, воздушные грузы, возрождение напарника и завершение боя.
3. Бой идёт до победы игрока, его гибели (без жетона) или конца времени; затем `HUD.ShowPostBattle()`
   с подробной статистикой, достижениями и кнопками «В ангар» / «Ещё бой».

## Боевые системы

| Система | Класс | Что делает |
|---|---|---|
| Машина | `TankController` | движение, опыт, уровни I–VII, смерть, возрождение |
| Модель и зоны | `TankRig` | делит FBX на корпус/башню/орудие, ставит коллайдеры зон |
| Башня | `TurretController` | поворот башни и подъём орудия на точку прицела |
| Орудие | `GunController` | перезарядка, боекомплект, разброс, бонусы модулей |
| Снаряд | `Shell` | баллистика, попадание, исключение собственной машины |
| Броня | `TankArmor`, `DamageSystem` | приведённая броня по углу, рикошет >72°, криты по модулям |
| Умения | `TankAbilities` | авиаудар + дым / ремонт / огненное кольцо / маскировка |
| Обзор | `VisionSystem` | круг 360° (или конус), линия видимости, скрытие необнаруженных |
| Зона | `ZoneController` | 6 фаз сужения, красная зона 22 урона/с |
| Лут | `LootBox`, `LootSpawner` | 90 ящиков, трофеи с машин, воздушный груз каждые 4 мин |
| Боты | `BotController`, `BotSquad` | три сложности, роли, фланги, парная тактика |
| Эффекты | `Fx` | попадания, рикошеты, взрывы, дым, вспышки, следы |
| Интерфейс | `HUD`, `MinimapWidget` | HUD, всплывающие цифры, лента, миникарта, панели |
| Профиль | `Profile`, `AchievementSystem` | статистика, 6 достижений, сохранение в PlayerPrefs |

## Формулы (что подкручивать в первую очередь)

- **Пробитие.** `приведённая броня = толщина / cos(угол между снарядом и нормалью)`, минимум 0.12.
  Пробитие падает на 8% каждые 100 м. Случайность ±15%. Угол больше 72° и нет запаса пробития → рикошет.
  Лобовая проекция получает ×1.35 к броне, гусеницы — 30 мм, орудие — 40 мм, МТО — 0.8 от кормовой брони.
- **Урон.** Пробитие — полный урон (`spec.damage`), непробитие — 12%, гусеницы — 35%, МТО — 60%,
  орудие — 25%, БК — 125%.
- **Криты.** Гусеница: скорость ×0.25, поворот ×0.35, самовосстановление 7 с.
  Двигатель: скорость ×0.55, ремонт 9 с. Орудие: перезарядка ×1.8, ремонт 8 с.
- **Опыт.** 0.35 за единицу урона, 120 за фраг, 45 за добычу, 160 за воздушный груз.
  Пороги уровней: 0 / 280 / 650 / 1150 / 1750 / 2450 / 3300.
  После перехода на новый уровень перезарядка первого выстрела режется вдвое (как в оригинале).
- **Зона.** Радиусы 1450 → 1150 → 880 → 620 → 380 → 180 м, фазы 150/150/135/120/105 с.
  Красная зона догоняет жёлтую со скоростью 12 м/с, урон 22 в секунду.
- **Боты.** Реакция 1.5 / 0.85 / 0.45 с, ошибка наведения 3.4° / 1.7° / 0.75°, дистанция боя
  250 / 320 / 360 м, шанс прицеливания в уязвимую зону 5% / 25% / 55%, фланг и умения — у сложного.

## Зависимости и окружение

- Unity 2022.3.62f2, встроенный рендер-пайплайн (Built-in), линейное цветовое пространство.
- Пакет `com.unity.ugui` — интерфейс (легаси-UI, без TextMeshPro: не требует импорта ассетов).
- Навигация: если не удалось испечь NavMesh автоматически, боты переключаются на прямое управление
  (в коде есть `patrolTarget` как запасной вариант).
- Blender-часть работает без GUI: `tools/blender.sh` поднимает venv с `bpy` и shim для X11/GL.
