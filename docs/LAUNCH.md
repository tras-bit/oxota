# Как запустить игру (пошагово, без программирования)

Игра — это проект Unity, лежащий в папке `game/`. Ниже — ровно те действия, которые нужны,
чтобы увидеть бой на своём компьютере. Все команды в терминале не нужны: только клики в Unity.

## 0. Что подготовить

1. **Unity Hub** — https://unity.com/download (бесплатно, нужна регистрация Unity ID).
2. В Hub: `Installs → Install Editor → 2022.3.62f2` (LTS). В списке модулей ничего отмечать
   не обязательно, кроме «Windows Build Support (IL2CPP)», если позже захочешь собрать `.exe`.
3. Папка с игрой: `game/` из этого репозитория (её можно просто скачать архивом).

## 1. Открыть проект

1. Unity Hub → `Add → Add project from disk` → выбери папку **`game`** (внутри неё лежат
   `Assets`, `ProjectSettings`, `Packages` — именно её и надо указывать).
2. Открой проект двойным щелчком. Первый импорт идёт 2–5 минут — Unity компилирует скрипты
   и импортирует модели с текстурами.
3. Посмотри внизу окно **Console** (Ctrl+Shift+C, если скрыто):
   - сообщения жёлтого цвета с текстом `Samsar` — это нормальные подсказки;
   - **красных ошибок быть не должно**. Если есть — скопируй текст и пришли мне, я поправлю.

## 2. Собрать игру из кусков (один пункт меню)

В верхнем меню Unity есть пункт **Samsar**:

1. **`Samsar → 0. СОБРАТЬ ВСЁ`** — главная кнопка. Она делает материалы, префабы техники
   и объектов, боевую сцену 3×3 км (город, промзона, лес, поля, железная дорога, станция)
   и главную сцену-ангар. Идёт 2–6 минут, показывает прогресс-бары. Прерывать не надо.
2. **`Samsar → Проверка готовности проекта`** — печатает в Console одну сводку: что готово,
   чего не хватает и что нажать. Если всё зелёное — можно играть.
3. Для ботов нужно один раз испечь навигацию: открой `Assets/Scenes/Battle.unity`,
   затем `Window → AI → Navigation → Bake`. Без этого игра работает, но боты ходят напрямик.

## 3. Играть

1. Открой `Assets/Scenes/Main.unity` (окно Project → `Assets/Scenes`).
2. Нажми **Play** (треугольник сверху по центру).
3. В ангаре: слева список машин (★ — спецмашины: «Бастион», «Арлекин», «Ворон»),
   справа — сложность ботов и «Соло / Взвод», внизу — ТТХ выбранной машины.
4. Кнопка **«В БОЙ»** (или Enter) — и ты в бою.

### Управление

| Клавиши | Действие |
|---|---|
| W / S, A / D | вперёд-назад, поворот корпуса |
| Мышь | прицел, камера |
| ЛКМ | выстрел |
| ПКМ | снайперский прицел ×8 |
| Колесо | приближение камеры |
| 1 / Q, 2 / E | умения (первое — авиаудар, второе — своё) |
| H | поделиться ремонтом с напарником |
| G | передать напарнику снаряды и заряды |
| Tab | статистика, Esc — пауза |

## 4. Что проверить в бою (приёмка)

- машина едет, башня идёт за мышью, снаряд летит время и нужен отвод;
- попадания: пробитие, рикошет, криты (гусеница, двигатель, орудие), оглушение от авиаудара;
- зона сужается, вне зоны идёт урон; на миникарте видны груз и зона;
- лут подбирается (снаряды, опыт, заряды умений, ремонт), трофеи падают с убитых;
- «Мародёры» (6 из 12 противников) бегают за добычей и отступают подранками;
- прокачка: за опыт выдаётся выбор из двух модулей прямо в бою (I–VII);
- после гибели/победы — итоги боя (место, урон, фраги, лут), достижения;
- поваленные деревья и разрушенные дома/заборы остаются обломками.

## 5. Если что-то не так

| Что видишь | Причина и лечение |
|---|---|
| Красные ошибки в Console | пришли текст — поправлю. Такого быть не должно: у меня есть проверки (`tools/checks/run_all.py`), но Unity в песочнице нет |
| Танки выглядят как капсулы, в HUD предупреждение «модель не найдена» | префабы не собраны → `Samsar → 0. СОБРАТЬ ВСЁ`, затем перезапусти Play |
| Машина белая/розовая | не создались материалы → `Samsar → 1. Материалы и префабы техники` |
| Боты стоят на месте | не испечена навигация → шаг 2.3 выше |
| Мало FPS | `Samsar → Настройки проекта` (тени, vSync, AA) или уменьши число ботов (ниже) |
| Нет звука | Unity по умолчанию включает звук; проверь ползунок Windows. Звук в игре процедурный, без внешних файлов |

## 6. Что можно менять самому (если захочется)

Все числа собраны в двух файлах, менять их можно прямо в Unity (файл → сохранить → Play):

- `game/Assets/Scripts/Core/GameSession.cs` — сколько противников (`BotsInBattle`, `MaraudersInBattle`),
  длительность боя (`BattleTime`), размеры зоны (`ZoneRadius`), опыт за действия, интервал воздушного груза;
- `game/Assets/Scripts/Core/TankSpec.cs` — характеристики всех 7 машин (прочность, броня, орудие, скорость).

Проверить, что баланс не сломался, можно без Unity: `python3 tools/balance_check.py` (или отчёт
в Unity: `Samsar → 4. Отчёт по балансу` → `docs/balance-report.md`).

## 7. Собрать Windows-версию (когда захочешь дать другу)

Быстрый путь: меню **`Samsar → 6. Собрать Windows-версию`** — проект сам соберёт `.exe`
в папку `Build/Windows` рядом с репозиторием и откроет её в проводнике. Рядом есть
`Samsar → 7. Открыть папку сборки`, если нужно просто посмотреть, что уже собрано.

Если хочешь сделать это руками:

1. `File → Build Settings…` → платформа **Windows, x86_64** → `Switch Platform`.
2. Убедись, что в списке сцен есть `Main` и `Battle` (Samsar → Настройки проекта добавляет их сам).
3. `Build` → выбери пустую папку (например, `SamsarBuild`) → дождись окончания.
4. Внутри появится `Samsar.exe` — его можно запускать без Unity, целиком папку можно заархивировать.

## 8. Если Unity ставить не хочется

Посмотреть, как игра выглядит, можно без движка:

- `assets/generated/` — рендеры техники, объектов и кадра боя (`battle_shot.png`);
- `site/preview.html` — страница проекта с картинками (открой в браузере);
- `docs/balance-report.md` — таблицы «кто кого за сколько убивает»;
- `python3 tools/checks/run_all.py` — все проверки проекта без Unity.
