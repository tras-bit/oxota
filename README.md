# Samsar — режим «Стальной охотник» (один режим, ничего больше)

Одиночный бой «последний выживший»: 30+ машин на карте 3×3 км, боты трёх уровней сложности,
сужающаяся зона (жёлтая → красная), прокачка техники прямо в бою с I по VII уровень, добыча и
воздушные грузы, два боевых умения на машину (первое — авиаудар). Донат и прогрессия отсутствуют.

**Движок:** Unity 2022.3.62f2 (Built-in RP) · **Модели и текстуры:** Blender, генерируются скриптами.

## Быстрый старт

```bash
# 1. Игра
Unity Hub → Add project from disk → папка game/
Открыть в Unity 2022.3.62f2 → меню «Samsar» → «0. СОБРАТЬ ВСЁ» → Play

# 2. Сайт с анкетой (60 вопросов) и превью проекта
cd /home/user/oxota && python3 -m http.server 8000
#   http://localhost:8000/site/index.html   — анкета
#   http://localhost:8000/site/preview.html — превью проекта с рендерами

# 3. Модели и текстуры (если нужно пересобрать ассеты)
tools/install_blender.sh                     # один раз: Blender headless + заглушки X11/GL
tools/blender.sh tools/make_textures.py      # 51 файл PBR-текстур 2К (добавлен набор metal_dark)
tools/blender.sh tools/build_models.py all   # 4 модели машин + 13 объектов окружения + рендеры
tools/blender.sh tools/tank_preview.py mt    # быстрые рендеры одной машины с трёх ракурсов

# 4. Проверки без Unity (движка в песочнице нет) — одним запуском
python3 tools/checks/run_all.py               # C# + модели FBX + комплектность ассетов + баланс
```

Отдельно: `tools/checks/check_csharp.py` (синтаксис, связи типов, присваивание результата void-метода,
число и типы аргументов, отсутствие API из Unity 2023+), `tools/checks/check_fbx.py`
(оси, единицы, схлопнутые детали и габариты моделей), `tools/checks/assets.py` (все ли файлы,
которые редакторские скрипты ищут по именам), `tools/balance_check.py` (таблицы дуэлей).
Для разбора C# нужен `pip install tree_sitter tree_sitter_c_sharp`.

## Что в репозитории

| Папка | Что внутри |
|---|---|
| `game/` | проект Unity: скрипты боя, ИИ, интерфейс, редакторские сборщики сцен |
| `tools/` | установка Blender, генераторы моделей техники и объектов, PBR-текстур, проверки кода |
| `assets/generated/` | превью-рендеры (техника, объекты); модели старых 8 машин в `tanks/` |
| `site/` | анкета на 60 вопросов и страница-превью проекта |
| `docs/` | ответы анкеты, архитектура, план работ |
| `archive/` | прошлая попытка целиком: Unity-проект `previous_session_project/`, её план и генератор моделей — не используется, оставлено для истории |

Играбельная версия живёт только в `game/Assets` (папка `archive/` на неё не влияет и в сборку не попадает).

## Уже играется

- 7 машин, все доступны сразу: 4 базовые (ЛТ «Ветер», СТ «Варяг», ТТ «Гранит», ПТ «Гроза») —
  по одной на класс, плюс 3 спецмашины (★ ТТ «Бастион», ★ ЛТ «Арлекин», ★ ПТ «Ворон») со своими
  умениями: стальная стена, форсаж, разведка.
- Броня по зонам с приведённой толщиной, рикошетами и критами (гусеница, двигатель, орудие, БК).
- Снаряды летят время, есть разброс, сведение и падение пробития с дистанцией.
- Зона из шести фаз: жёлтая предупреждает, красная наносит 22 урона в секунду.
- Лут: 90 ящиков на карте, трофеи с уничтоженных машин, воздушный груз по расписанию.
- Возрождение после уничтожения — только по жетону, найденному в луте.
- Прокачка I–VII: 12 модулей, на каждом уровне выбор из двух; бонус −50% к перезарядке выстрела.
- Боты: маршруты, сбор лута, бой с дистанции по классу, фланговые обходы, уход в зону, умения.
- ИИ-напарник по взводу: следует за игроком, ему можно передавать ремонт клавишей H.
- HUD: прочность, состояние модулей, броня, уровень и опыт, снаряды, заряды умений, миникарта
  со границей зоны и воздушными грузами, лента уничтожений, всплывающие цифры урона.
- Итоги боя: место, фраги, урон, собранный лут, время; шесть достижений за особые действия.

## Ограничения текущей версии

- Онлайн-мультиплеера нет — по плану анкеты он идёт после одиночной версии.
- Звук процедурный (`Audio/Sfx.cs`): выстрелы, попадания, рикошеты, взрывы, двигатель, лут — синтез
  кодом, без внешних файлов; позже меняется на бесплатные библиотеки в тех же точках вызова.
- Если Unity не испёк NavMesh автоматически, боты ходят напрямую: испеки вручную
  (Window → AI → Navigation → Bake) — станет заметно умнее.
