# SAMSAR — «Стальной охотник»

Игра: **один режим — «Стальной охотник»**, королевская битва на танках.
Платформа: ПК (Windows). Движок: **Unity 2022.3.62f2**.

## Быстрый старт

**Игра.** Unity Hub → Add → папка `game/Samsar` → открыть в Unity 2022.3.62f2.
При первом запуске проект сам создаст сцены и настройки (скрипт `Assets/Editor/SamsarProjectSetup.cs`),
дальше: открыть `Assets/Scenes/MainMenu.unity` и нажать Play. Управление — в `game/README.md`.

**Анкета (если нужно перепройти или что-то поменять).**

```bash
cd site && python3 -m http.server 8000
```

**Модели техники (Blender, headless).**

```bash
tools/install_blender.sh                 # один раз: Blender 4.5 LTS как модуль bpy + shim-библиотеки
tools/blender.sh tools/build_tanks.py    # собрать 8 машин: FBX + GLB + blend + превью + PBR-текстуры
```

Результат: `assets/generated/tanks/*.fbx|.glb|.blend|_preview.png`, `assets/generated/textures/tank_*.png`
(общие PBR-текстуры), `assets/generated/tanks/manifest.json` (полигонаж по машинам).

## Что уже готово

**Игра (этап 1 — играбельный прототип).** Меню → 3D-ангар (8 машин, ТТХ, настройки боя) → бой 3×3 км
с 30+ машинами → экран результатов. Внутри: снаряды с полётом и отводом, рикошеты и приведённая броня,
критические модули, сужающаяся зона (жёлтая → красная), лут и воздушный груз, уровни I–VII с выбором
двух модулей, 8 машин и 8 боевых умений, боты-мародёры трёх уровней, разрушаемая карта с интерьерами
и железнодорожной станцией, полный HUD, достижения, полигон, процедурный звук и эффекты.

**Модели.** 8 машин генерируются скриптом Blender (13–17 тыс. треугольников на машину): корпус со скосами
и сварными швами, ходовая с отдельными траками, башня с люками/приборами/укладкой, орудие с дульным тормозом,
комплекты доп. брони (экраны, ДЗ, брёвна, канистры) — по типу машины. Экспорт FBX/GLB, превью-рендеры,
процедурные PBR-текстуры (albedo/normal/ORM).

**Blender в песочнице.** Системных библиотек OpenGL/X11 здесь нет, поэтому Blender поставлен как
headless-модуль `bpy` в отдельное окружение вне репозитория, а недостающие библиотеки заменены
сгенерированным shim-файлом (`tools/make_gl_stubs.py`). Работает моделирование, рендер Cycles на CPU
и экспорт FBX/GLB. GUI-окна в песочнице нет — только скрипты.
