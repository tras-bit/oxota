# Samsar — режим «Стальной охотник» (Unity 2022.3.62f2)

Одиночный бой «последний выживший»: 30+ машин, боты трёх уровней сложности, сужающаяся зона
(жёлтая → красная), прокачка машины прямо в бою с I по VII уровень, добыча и воздушные грузы,
2 боевых умения на машину (первое — авиаудар).

## Как запустить

1. Unity Hub → **Add project from disk** → папка `game`.
2. Открыть проект в **Unity 2022.3.62f2** (нужна установка ровно этой версии; подойдёт любая 2022.3.xx).
3. В меню сверху: **Samsar → 0. СОБРАТЬ ВСЁ**. Скрипт создаст материалы, префабы и обе сцены
   (террейн 3×3 км, город, лес, железная дорога, станция, техника, лут).
4. Нажать **Play** — откроется 3D-ангар: выбор машины, сложности и взвода → **«В БОЙ»**.

Если боты ходят напрямик, а не по дорогам — испеки навигацию вручную:
**Window → AI → Navigation → Bake**. Игра работает и без него (появится предупреждение).

## Управление

| Клавиши | Действие |
|---|---|
| W / S | ход вперёд / назад |
| A / D | поворот корпуса |
| Мышь | прицел, камера |
| ЛКМ | выстрел |
| ПКМ | снайперский прицел ×8 |
| Колесо мыши | приближение камеры |
| 1 / Q | умение 1 (авиаудар) |
| 2 / E | умение 2 (своё у машины) |
| H | поделиться ремонтом с напарником |
| Tab | состояние боя |
| Esc | пауза |

## Уже реализовано (по ответам анкеты)

- 4 машины (ЛТ/СТ/ТТ/ПТ-САУ), все доступны сразу, без прогрессии и доната.
- 30+ участников боя: игрок, ИИ-напарник по взводу и боты 5–10+; сложность ботов настраивается (3 уровня).
- Прокачка в бою I–VII, на каждом уровне выбор из двух модулей; после уровня орудия перезарядка режется вдвое.
- Зона: красная (урон 22/с) и жёлтая (предупреждение с таймером), 6 фаз сужения.
- Добыча: ящики на карте, трофеи с уничтоженных, «Воздушный груз» по расписанию (виден всем на карте).
- Возрождение — только при подборе жетона «Возрождение» из лута.
- 2 умения на машину: авиаудар (у всех) + дым / ремонт / огненное кольцо / маскировка.
- Броня по зонам: корпус, башня, гусеницы, МТО, орудие, БК; рикошеты, приведённая броня по углу.
- Криты: сбитая гусеница (скорость ×0.25), повреждённый двигатель (−45% скорости), разбитое орудие (+80% перезарядки).
- Обзор 360°, автообнаружение в 50 м, скрытие необнаруженных противников; опционально конус 100°.
- Полный HUD: прочность, модули, броня, уровень машины, снаряды, умения с зарядами, миникарта.
- Разрушаемые дома, заборы, контейнеры, деревья; внутрь ангаров можно заехать.
- Статистика после боя и 6 достижений за особые действия.
- Анимация ходовой: прокрутка траков, качание корпуса на подвеске, откат ствола, следы гусениц и пыль.
- Звук: процедурные выстрелы, попадания, рикошеты, взрывы, двигатель, лут, предупреждение зоны.

## Проверки без Unity

```
python3 tools/checks/run_all.py        # всё сразу: C#, модели FBX, ассеты, баланс (запуск из корня репозитория)
```

## Проверка баланса без запуска игры

```
python3 tools/balance_check.py
```

Скрипт разбирает числа прямо из `Assets/Scripts/Core/TankSpec.cs` и печатает таблицу
«кто кого за сколько выстрелов/секунд убивает» в лоб и с доворотом корпуса на 60°.
Если в бою что-то кажется нечестным — сначала смотрим сюда, потом в редакторе
через меню **Samsar → 4. Отчёт по балансу** (50 дуэлей на каждую пару на настоящей математике
игры, отчёт складывается в `docs/balance-report.md`).

## Ограничения текущей версии

- Онлайн-мультиплеер пока не реализован (по анкетному плану — после одиночной версии).
- Звук процедурный, без внешних библиотек: библиотеку бесплатных звуков подключим в этапе 2.
- Здания «оседают» целиком и оставляют обломки; разрушение по частям — этап 2.
- Навигацию ботов нужно испечь в редакторе (иначе ходят напрямик).
