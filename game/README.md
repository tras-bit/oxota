# SAMSAR — игра (Unity 2022.3.62f2)

Один режим: «Стальной охотник» — королевская битва на танках. 30+ машин в бою, зона сжимается,
прокачка прямо в бою (I–VII), добыча и воздушный груз, два боевых умения, боты-мародёры,
карта 3×3 км с городом, лесом, полями и железнодорожной станцией.

## Как запустить

### Вариант 1 — открыть этот проект (рекомендуется)

1. Unity Hub → **Add** → **Add project from disk** → выбери папку `game/Samsar`.
2. Открой проект в Unity **2022.3.62f2** (другой 2022.3.x тоже подойдёт).
3. Unity сама создаст недостающие настройки проекта и при первом запуске выполнит
   автонастройку (скрипт `Assets/Editor/SamsarProjectSetup.cs`):
   создаст сцены `Assets/Scenes/*.unity`, добавит их в Build Settings, выставит качество и разрешение.
   Если автонастройка не сработала — меню **Samsar → Настроить проект (создать сцены)**.
4. Открой `Assets/Scenes/MainMenu.unity` и нажми **Play**.

### Вариант 2 — перенести код в свой проект

Создай в Unity Hub новый проект (3D, 2022.3.x), затем скопируй в него:

- `Assets/Scripts` — весь игровой код
- `Assets/Editor` — автонастройка сцен и параметров

После копирования: меню **Samsar → Настроить проект (создать сцены)**, открыть `Assets/Scenes/MainMenu.unity`, Play.

## Управление

| Клавиши | Действие |
|---|---|
| W/S | вперёд / назад |
| A/D | поворот корпуса |
| Мышь | обзор, прицел (башня следует за прицелом) |
| ЛКМ | выстрел |
| ПКМ | снайперский прицел ×8 |
| Q / E | боевые умения машины |
| Space | тормоз |
| M | большая карта |
| Tab | таблица боя |
| Esc | пауза, настройки, выход в меню |

В меню и ангаре: `Enter` — в бой, стрелки/A-D — выбор машины, ЛКМ + мышь — вращение камеры, колесо — зум.

## Что уже реализовано (этап 1 — играбельный прототип)

- **Ядро режима**: 30+ участников (настраивается 10–40), каждый сам за себя, взвод из двух (игрок + союзник-бот),
  победа — остаться последним; возрождение только через подобранный заряд «Возрождение».
- **Зона**: жёлтая граница сужается по этапам, за 30 секунд становится красной, вне зоны — постоянный урон,
  визуальная стена и кольцо, предупреждающий звук.
- **Прокачка в бою**: уровни I–VII, опыт за урон, уничтожение и добычу, на каждом уровне выбор из двух модулей
  (урон, перезарядка, пробой, разброс, сведение, прочность, броня, скорость, обзор, ремонт, боекомплект).
- **Урон и броня**: приведённая броня по углу, рикошеты, непробития, потеря пробития на дистанции,
  модули (гусеница, двигатель, орудие) с автопочинкой, критические попадания.
- **Добыча**: ящики на карте (респавн), трофеи с уничтоженной техники, воздушный груз по расписанию с парашютом,
  содержимое: снаряды, опыт, ремонт, заряды умений, экран, «Возрождение».
- **8 машин** трёх классов (ЛТ, СТ, ТТ, ПТ-САУ), у каждой два умения: авиаудар, артзалп, разведдрон,
  дымовая завеса, форсаж, полевой ремонт, экран защиты, огненное кольцо.
- **Боты-мародёры**: 3 уровня сложности, держат дистанцию по классу, объезжают препятствия, собирают лут,
  уходят из зоны, применяют умения, стреляют с упреждением.
- **Обнаружение**: круговая зона видимости 360°, автообнаружение в упор (50 м), учёт препятствий, дым скрывает машину.
- **Карта 3×3 км**: сгенерированный рельеф, заброшенный город с заезжаемыми интерьерами, деревня,
  лес (900+ деревьев), поля со стогами, железнодорожная станция с поездом, дороги, река в низинах.
- **Разрушаемость**: дома, заборы, деревья, стога, вагоны поезда и водонапорная башня.
- **HUD**: прочность, состояние модулей, броня, боекомплект и перезарядка, уровень машины и опыт,
  сводка урона, миникарта с зоной и подсвеченными целями, большая карта, таблица боя, всплывающий урон,
  выбор модуля, панель после гибели, пауза с настройками.
- **Экран результатов**: место, урон, точность, доля пробитий, достижения (8+ видов), итоговая таблица,
  общая статистика игрока.
- **Ангар**: 3D-просмотр всех 8 машин, ТТХ, умения, настройки боя (участники, сложность, взвод).
- **Полигон**: отдельная сцена для проверки стрельбы по мишеням.
- **Прочее**: процедурный звук и эффекты (выстрелы, попадания, взрывы, дым, трассеры, клубы пыли),
  генерация текстур и материалов кодом — внешних ассетов не требуется.

## Сборка для Windows

Меню Unity: **Samsar → Собрать сборку для Windows**. Готовый `.exe` появится в `game/Builds/Windows`
(папку Unity создаёт сам, в git она не попадает). Сборка включает все пять сцен и настройки проекта.

В `Assets/Resources/Models` уже лежат 8 моделей (`*.fbx`), сгенерированных скриптом
`tools/build_tanks.py`; в `Assets/Resources/Textures` — общие PBR-текстуры (albedo, normal, ORM).
Игра подхватывает их автоматически: заменяет примитивную геометрию, подгоняет масштаб и разворот,
оставляя коллайдеры и точки вращения башни и орудия. Отключить и вернуться к примитивам можно
в паузе: «Модели из Blender».

Пересобрать модели (нужен Blender на ПК или песочница агента):

```bash
tools/blender.sh tools/build_tanks.py             # все 8 машин
tools/blender.sh tools/build_tanks.py --lod high  # детальнее
tools/blender.sh tools/build_tanks.py --only tur  # одна машина
```

## Известные ограничения прототипа

- Текстуры техники — один общий PBR-набор 1К на все машины (отличаются оттенком кузова).
  Отдельные наборы 2К на каждую машину — следующий шаг.
- Модели собраны из параметрических примитивов: силуэт и детали машинные, но это не копии
  реальных танков (юридически безопасно и быстро пересобирается скриптом).
- Онлайн-мультиплеера нет: бой против ботов (по ответам анкеты онлайн — позднее).
